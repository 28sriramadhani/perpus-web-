# Sistem Informasi Perpustakaan

## Deskripsi
Sistem informasi perpustakaan berbasis web untuk 
pengelolaan data anggota, buku, dan peminjaman.

## Tech Stack
- PHP Native
- MySQL
- HTML, CSS, JavaScript

## Fitur
- CRUD Data Anggota
- CRUD Data Buku
- CRUD Data Peminjaman
- Laporan peminjaman
